# fps60 assets

- `icon.svg`: source of the home screen tile icon.
- `icon0.png`: 512x512 render of `icon.svg`, embedded into `NetDis.elf` and
  installed as the tile's `sce_sys/icon0.png`. Re-render it after editing the
  SVG, for example by opening the SVG in Chromium at 1024x1024 and saving a
  screenshot scaled to 512x512, or with any SVG renderer that has a bold sans-serif font.
